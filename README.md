# sculpture
Тут будет сайт про памятники.
Этапы разработки
Итерация 1: «Скелет»

Создать index.html и подключить Tailwind.
Написать data.js с двумя памятниками.
Написать простой JS-цикл, который выводит эти два памятника на страницу в виде простых картинок.
Итерация 2: «Интерактив»

Создать HTML-разметку модального окна (скрытую по умолчанию).
Реализовать открытие окна при клике на карточку.
Сделать так, чтобы в окно подставлялись данные именно того памятника, на который нажали.
Итерация 3: «Игра»

Разделить содержимое окна на две части: «Загадка» и «Профиль».
Сделать кнопку переключения между ними.
Добавить анимацию появления текста.
Итерация 4: «Полировка»

Добавить ссылки на карты.
Реализовать кликабельных «друзей» (при клике на друга окно закрывается и открывается профиль другого памятника).
Оптимизировать сайт для мобильных телефонов.
